# Phaladeepika (Mantreshvara) — reading from the Sanskrit

Source: the Sanskrit e-text at sanskritdocuments.org, file `phaladIpika.itx` (transliterated and proofread by Radu Canahai, update 28 Aug 2021; "prepared by volunteers ... for personal study and research"). 28 chapters, about 870 verses, read in a browser on 12 Nov 2026. The translations here are this project's own; the Sanskrit is not reproduced.

The verses are in long ornate metres and the e-text has visible typing slips, so readings are more exposed to error than in Parashara's plain verse. [?] marks any line whose reading is uncertain. Conventions and exclusions are the same as in `../bphs/README.md` (no death, widowhood, childlessness, child-sex or character-label wordings are carried into readings).

Why this text matters here: the knowledge base cited Phaladeepika 41 times through an English website (siva.sh) whose glosses are machine-made. Those citations are re-checked against the Sanskrit in these files, and each file ends with the result.
